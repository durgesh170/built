# BUILT Marketing — HTML/CSS clone

Static HTML/CSS recreation of [built-marketing.preview.emergentagent.com](https://built-marketing.preview.emergentagent.com).

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Pages

- `index.html` — full homepage (hero, services, selected work, clients, process, industries, about, contact, footer)
- `work.html` — portfolio / work grid with Drive video previews

## Stack

- Plain HTML + CSS + a small `js/main.js` (nav, accordion, tabs, form UX)
- Fonts: Bebas Neue, Playfair Display, Oswald, Manrope (Google Fonts)
- Images under `assets/` (portfolio stills, studio photo, 27 client logos, work thumbnails)
